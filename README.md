# 메이플 타이머 (개인용)

메이플스토리 화면을 공유하면 브라우저 안에서 분석해서 소리로 알려주는 보조 도구입니다.
게임 입력·메모리·패킷·파일에는 접근하지 않고, 공유한 화면도 외부로 보내지 않습니다.

> ⚠️ 비공식 도구입니다. 넥슨은 원본 서비스(maple-timer.com)에 "화면 인식 자동 알림은 Open API 이용 범위를 넘고 매크로처럼 악용될 우려가 있다"며 중단을 요청했습니다. 사용에 따른 계정 제재 등의 책임은 본인에게 있습니다.

## 실행

**가장 쉬운 방법 (Windows):** 폴더의 `start.bat` 을 더블클릭하면 필요한 파일을 설치하고, 서버를 켠 뒤 **메이플 타이머 전용 창**을 열어 줍니다.

- 전용 창에서는 '화면 공유 시작'을 누르면 **MapleStory 창이 자동으로 선택**돼요 (목록에서 고를 필요 없음).
- 서버는 작업 표시줄의 '메이플 타이머 서버' 창으로 최소화돼 있고, 그 창을 닫으면 꺼져요.
- 전용 창은 일반 Chrome 과 설정이 따로 저장돼요. 일반 Chrome 에서 쓰던 설정은 **설정 > 설정 파일로 내보내기 / 불러오기**로 옮기세요.
- 메이플 패처(업데이트 창) 제목도 'MapleStory' 라서, 패처가 떠 있을 땐 그 창이 잡힐 수 있어요. 게임이 켜진 뒤에 공유를 시작하세요.

직접 실행하려면:

```bash
npm install
npm run dev
```

Chrome 또는 Edge 에서 http://localhost:5173 을 엽니다.

### 다른 컴퓨터에서

1. [Git](https://git-scm.com) 과 [Node.js](https://nodejs.org) (24 이상) 설치
2. `git clone https://github.com/ilyoon98/MapleTimer.git`
3. 받은 폴더의 `start.bat` 더블클릭
4. 원래 컴퓨터에서 **설정 > 설정 파일로 내보내기** 한 파일을 새 컴퓨터에서 **설정 파일 불러오기** (영역·학습한 숫자 포함. 해상도가 다르면 영역은 다시 선택)

코드가 바뀌면 폴더에서 `git pull` 하면 최신 버전이 됩니다.

`npm run build` 로 만든 `dist/` 폴더는 정적 파일이라 아무 웹 서버(https 또는 localhost)에 올려서 쓸 수 있습니다.

## 기능

| 기능 | 영역 | 방식 |
|---|---|---|
| 스킬 알림 | 퀵슬롯 아이콘 | 아이콘이 어두워지거나 쿨타임 숫자가 나타나는 순간 = 스킬 사용 → 지속시간 끝나기 N초 전 알림. 쿨타임 도중 켜도 숫자로 역산 |
| 룬 알림 | 미니맵 안쪽 | 등록한 룬 아이콘(템플릿) 또는 색상으로 찾기, 2번 확인 후 알림, 맵 이동 감지 |
| 사냥 멈춤 | 경험치 숫자 / 스킬 아이콘 / MP | N초 동안 영역이 안 바뀌면 알림 |
| 버프칸 감지 | 우상단 버프칸 | 등록한 아이콘의 **남은 시간 숫자를 읽어** 끝나기 전 알림 (야누스·파운틴 정밀 감지, 자석펫 연장 반영), 사라지면 알림, 특수 코어 쿨타임 카운트다운 |
| 부스터 종료 | 화면 위쪽 부스터 '남은시간' | 디지털 시계 모양 숫자("36.83")에서 초만 학습 없이 읽어 끝나기 전 알림 (소수점 아래는 안 읽음). 퀘스트 알림 글자가 겹쳐도 읽음 |
| 일반 타이머 | - | 재획 비약 30분, 유니온의 부/행운 등 수동 타이머, 줄에서 바로 시간 고르기(30분/20분/10분/2시간/직접), 타이머별 켜기/끄기, 버프 연계 자동 시작 |
| PIP 타이머 | - | 게임 위에 항상 떠 있는 작은 창 (Chrome/Edge), 크기 선택, 맨 위에 '다음 알림' 크게, 보여 줄 항목 고르기, 알림 중 강조(은은하게/보통/강하게/점멸), 알림색, 배경에 공유 중인 게임 화면 |

공통: 알림 시점(음수면 종료 후), 반복 알림(2/3/5초 간격), 음성(TTS, 문장은 항목 이름으로 자동)/비프음/내 소리 파일, 마스터 볼륨과 옆의 음소거 버튼, 랜덤 지연(설정, 첫 알림 0~2초), 울리는 알림 멈춤, 화면 공유 끊김 알림, 테마.

### 숫자 읽기와 추가 학습

실제 게임 버프칸을 녹화해 모은 숫자 1260개로 만든 **게임 숫자 모양이 기본으로 들어 있어서** 학습 없이도 쿨타임·버프 숫자를 읽습니다 (녹화한 숫자의 98%).
자꾸 못 읽는다면 아래처럼 하면 **내 화면에서 자동으로 더 배워서** 같이 씁니다.

1. 쿨타임이 10초 이상인 스킬의 퀵슬롯 영역을 잡아 둡니다.
2. 스킬을 쓰고 쿨타임 숫자가 **한 자리(9 이하)가 될 때까지** 지켜봅니다 → 두 자리에서 한 자리로 바뀌는 순간을 10→9 로 보고 앞뒤로 세어 0~9 를 학습합니다. (게임이 5초 미만 숫자를 안 보여줘도 괜찮아요)
3. 버프칸에서 남은 시간을 읽는 버프가 끝날 때도 같은 방식으로 더 배웁니다.

설정 > 숫자 학습에서 상태를 보거나 초기화할 수 있고, '설정 파일로 내보내기'에 학습한 숫자도 함께 들어가서 다른 컴퓨터로 옮길 수 있습니다.

각 항목의 ▾ 를 누르면 **진단** 화면에서 실제로 잘린 영역과 수치를 보고 기준값을 조절할 수 있습니다.

## 아직 실제 게임에서 확인이 필요한 것

지금까지는 개발용 가짜 화면으로만 검증했어요. 실제 게임에서 처음 써 볼 때 아래를 확인해 주세요.

- **스킬**: 진단의 '사용 가능 기준' 이미지에 숫자가 없는지, 스킬을 쓰면 상태가 '쿨타임'으로 바뀌는지 (안 바뀌면 '어두움 비율' 조정)
- **룬**: 색상 방식으로 오탐/미탐이 있으면 룬이 떴을 때 '룬 아이콘 등록'
- **버프칸**: 버프가 있을 때 일치도가 '일치 기준'보다 높고, 없을 때 낮은지
- **부스터**: 부스터가 켜져 있을 때 읽은 값이 화면 숫자와 같은지 (멈춰 있는 화면으로는 36.83 을 정확히 읽음)
- **어두운 맵**: 밝은 맵에서 어두운 맵으로 이동한 뒤 3초쯤 지나면 스킬·버프 감지가 다시 도는지 (전엔 계속 '화면 전환 중'으로 쉬었음)
- **공유 다시 켜기**: 공유가 끊긴 사이 쓴 스킬이 다시 켠 시각이 아니라 쿨타임 숫자로 맞는 시각에 잡히는지

문제가 있으면 **설정 > 진단 파일 저장**으로 그 순간을 저장해 두세요. 화면과 설정이 함께 들어 있어 원인을 찾기 쉬워요.

## 개발

- `npm test` — 감지 로직 단위 테스트
- `http://localhost:5173/?demo` — 개발 모드 전용 가짜 게임 화면으로 화면 공유 없이 시험
  (`k`: 스킬 사용(쿨 15초), `s`: 경험치 멈춤/재개, `b`: 버프 아이콘 켜고 끄기(70초), 룬은 10초마다 나타남, 부스터는 시작 5초 뒤 60초 카운트다운)
  숫자는 실제 게임 모양(노란 숫자, 부스터는 디지털 시계 모양)으로 그려서 학습 없이 기본 숫자 읽기를 시험할 수 있음
- 개발 모드에서는 콘솔의 `window.__mapleTimer` 로 잘라낸 영역·상태를 볼 수 있음

```
src/
  capture/   화면 공유 스트림 → 프레임 → 영역 잘라내기
  cv/        영상처리 (밝기, 연결요소, 마스크 템플릿 매칭, 숫자 읽기)
  detect/    기능별 감지기 (퀵슬롯, 룬, 변화 없음, 나타남/사라짐, 숫자 학습)
  alerts/    소리 재생, 알림 반복/지연
  engine/    250ms 워커 tick 으로 모든 감지·알림 실행 (engine.ts 메인 루프, 기능별 skills·buffs·booster·runeStall·timers)
  state/     설정(localStorage) 저장
  ui/        패널, 영역 선택 창, PIP
```
