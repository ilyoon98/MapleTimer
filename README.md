# 메이플 타이머 (개인용)

메이플스토리 화면을 보고 솔 야누스·에르다 파운틴·룬·버프·부스터 등을 때맞춰 소리로 알려 주는 Windows 앱입니다.
게임 입력·메모리·패킷·파일에는 접근하지 않고, 화면은 이 PC 안에서만 분석합니다.

> ⚠️ 비공식 도구입니다. 넥슨은 원본 서비스(maple-timer.com)에 "화면 인식 자동 알림은 Open API 이용 범위를 넘고 매크로처럼 악용될 우려가 있다"며 중단을 요청했습니다. 사용에 따른 계정 제재 등의 책임은 본인에게 있습니다.

## 설치

1. [Releases](https://github.com/ilyoon98/MapleTimer/releases/latest) 에서 `MapleTimer-Setup-<버전>.exe` 를 받아 실행합니다.
2. 바탕 화면의 **메이플 타이머** 를 켜고 **메이플 연결** 을 누릅니다.

새 버전이 나오면 앱이 알아서 받아 두고, 다음에 켤 때 바뀝니다.
앱이 켜져 있는 동안에도 10분마다 새 버전을 확인합니다.
화면 위쪽과 설정에 현재 버전이 표시됩니다. **설정 → 업데이트 확인**에서 직접 확인하거나, 다운로드가 끝나면 **지금 업데이트**를 누를 수 있습니다.
확인에 실패하면 다시 확인할 수 있도록 상태를 표시합니다.

## 쓰는 법

1. **메이플 연결** → 메이플스토리 창을 고릅니다 (추천 창이 미리 골라져 있어요).
2. 쓸 알림을 켭니다. 위치는 대부분 자동으로 찾고, 손볼 게 있으면 그 칸에 노란 줄로 알려 줍니다.
3. **PIP 타이머** 를 열면 게임 위에 늘 떠 있는 작은 창이 생깁니다. 오른쪽 위 ⚙ 에서 글자 크기·알림 모양을 바꾸고, 창 크기는 끌어서 바꿉니다.

게임 안 설정 (설정 > UI): UI 크기 **최적 비율**, 퀵슬롯&버프 시간표시 **중앙, 크게 · 분 + 초**, 버프 정렬 옵션 **모두 켜기**.

알림이 이상하면 바로 **설정 > 문제가 생겼을 때 > 진단 파일 저장** 을 눌러 두세요. 최근 30초의 감지 영역이 같이 담겨서 그 상황을 다시 돌려 보며 고칠 수 있습니다.

알림이 울릴 때 게임 화면·해당 감지 영역·판독값을 자동으로 남깁니다. **알림 캡처 보기**에서 확인하거나 진단 파일에 함께 저장할 수 있습니다.
기록은 이 PC 안에 최대 30건·24 MiB만 보관합니다. 플레이 중 팝업이나 별도 파일 창은 뜨지 않습니다.
각 캡처에 **맞아요 / 틀렸어요** 를 눌러 두고, 울려야 했는데 안 울렸으면 PIP 아래 **놓침** 을 눌러 그 기능을 고르세요. 이 표시가 진단 파일에 같이 담겨 자동 분석에 쓰입니다.

0.3.1: 마을의 가는 분홍 표식을 룬으로 잘못 읽는 문제와, 퀘스트 글자가 겹치면 부스터 위치 탐색이 실패하는 문제를 수정했습니다.

0.3.2: 설정을 즉시 앱 파일에 저장하고 정상 백업을 유지합니다. 설치 위치나 버전이 달라져도 `%APPDATA%/메이플 타이머 개인용/settings`를 사용하며, 이전 브라우저 저장소의 설정도 자동으로 옮깁니다.

0.3.3: 연결 화면의 추천 메이플 창을 가장 큰 카드로 표시합니다. 특수 코어는 일시 중단해 메인 화면·PIP·감지·알림에서 제외하며 저장된 항목은 보존합니다.

0.3.4: 정밀 스킬 위치는 공유 게임 화면에서 기본 버프칸·좌측 하단·우측 하단 중 한 곳을 눌러 두 스킬에 함께 적용합니다. 각 스킬 설정은 알림 시점·소리 위주로 줄이고 반복·볼륨은 접어 뒀습니다. 자동 업데이트 확인 주기는 10분입니다.

0.3.5: 알림 캡처마다 맞아요/틀렸어요 표시, PIP 아래 놓침 버튼(안 울린 순간 남기기), 진단 파일 자동 분석(`npm run evidence:check`). PIP 에 부스터 종료 알림을 켜 두면 부스터 줄이 늘 보입니다. 칸 제목에 게임 아이콘을 넣었습니다.

0.3.6: PIP 의 다음 알림 칸을 늘 같은 자리에 둬서(알림이 없으면 "없음") 아래 줄이 들썩이지 않습니다. 룬·사냥 멈춤도 다른 항목처럼 한 줄씩 맨 아래에 보입니다.

## 기능

| 기능 | 보는 곳 | 하는 일 |
|---|---|---|
| 스킬 알림 | 기본 버프칸 / 버프 즐겨찾기(좌·우 하단) | 솔 야누스: 새벽·에르다 파운틴 아이콘의 남은 시간을 읽어 끝나기 전 알림 |
| 룬 알림 | 미니맵 (자동으로 찾음) | 룬이 두 번 연달아 보이면 알림, 맵 이동 감지 |
| 사냥 멈춤 | 경험치 숫자 줄 / 스킬 아이콘 / MP | N초 동안 안 바뀌면 알림 |
| 버프 종료 · 특수 코어 | 오른쪽 위 버프칸 | 등록한 아이콘의 남은 시간을 읽어 끝나기 전 알림, 특수 코어 쿨타임 |
| 부스터 | 화면 위쪽 (자동으로 찾음) | 디지털 시계 모양 숫자를 읽어 끝나기 전 알림 |
| 일반 타이머 | - | 재획 비약 30분 등 화면에 없는 시간, 버프 연계 자동 시작 |
| PIP 타이머 | - | 항상 위 작은 창, 맨 위에 '다음 알림', 글자 크기·알림 모양·알림색 |

숫자는 실제 게임에서 모은 숫자 모양(1,260개)이 들어 있어서 학습 없이 읽고, 쓰다 보면 이 PC 화면에 맞춰 자동으로 더 배웁니다.

## 개발

```bash
npm ci
npm run desktop        # 빌드 후 앱 실행 (start-desktop.bat 과 같음)
npm run dev            # 브라우저에서 화면만 개발 (http://localhost:5173)
npm test               # 단위 테스트
npm run desktop:pack   # 설치 파일 만들기 → release/
```

- **배포**: README 에 `0.3.x: 바뀐 점` 한 줄을 적고 `npm version patch` (버전 올리기 + 커밋 + `v0.3.x` 태그) → `git push --follow-tags`. 태그가 올라가면 GitHub Actions(`.github/workflows/release.yml`)가 Windows 에서 테스트 → 설치 파일 만들기 → Releases 에 `.exe`·`.blockmap`·`latest.yml` 을 올리고, README 의 그 줄을 릴리스 설명으로 씁니다. 따로 토큰이 필요 없습니다. 앱은 `latest.yml` 을 보고 새 버전을 받습니다.
- `npm run desktop:release` — 같은 일을 이 PC 에서 직접 (환경 변수 `GH_TOKEN` 필요).
- `npm run evidence:check -- <진단 파일 또는 폴더>` — 알림 캡처를 지금 감지 코드로 다시 읽어 기능별로 정리합니다 (맞음·틀림·놓침, 연달아 울림·검은 화면 같은 의심). '틀림'·'놓침' 기록은 `src/detect/fixtures/evidence/` 에 회귀 테스트로 저장되고, `npm test` 가 매번 확인합니다. 부스터 '틀림'은 실제 남은 초를 `expected.value` 에 채워야 돌고, 고쳐서 통과하면 `fixed: true` 로 바꿉니다.
- `node scripts/smoke-desktop.mjs` — 앱 자동 점검 (`--check-settings --fresh-profile`, 설치 결과는 `--packaged`).
- `http://localhost:5173/?demo` — 개발 모드 전용 가짜 게임 화면 (`k` 스킬, `s` 경험치 멈춤, `b` 버프 켜고 끄기).
- `http://localhost:5173/?replay` — 진단 파일의 30초 녹화를 화면 공유처럼 재생.
- 개발 모드 콘솔의 `window.__mapleTimer` 로 잘라낸 영역·상태를 볼 수 있습니다.

```
electron/  앱 창·화면 고르기·자동 업데이트
src/
  capture/   화면 공유 스트림 → 프레임 → 영역 잘라내기
  cv/        영상처리 (템플릿 매칭, 숫자 읽기)
  detect/    기능별 감지기
  alerts/    소리 재생, 알림 반복
  engine/    0.25초마다 감지·알림 (search/ 는 버프칸 탐색 워커)
  state/     설정 저장
  ui/        칸, 영역 선택 창, PIP, 안내
```
